About

Data analysts lose hours to files they can't trust.

Before a dashboard goes out, someone has to ask: does this data actually match the source? Is anything missing, duplicated, or just... off? Data Sentinel automates that question — combining deterministic rule checks with an unsupervised ML model that learns what "normal" looks like in your specific file, every time it's uploaded.

Process

From raw upload to a trusted report

01

Upload your CSV

Drop in any dataset — sales, HR, logs, survey data. No setup, no schema to define in advance.

02

Automated validation runs

Structural checks, rule-based checks, and an Isolation Forest model score every row for anomalies — all in real time.

03

Get a report you can act on

See flagged rows with plain-English reasons, ask the built-in assistant questions, and export a PDF summary.

Features

Everything a validation pass should cover

🧱

Structural checks

File integrity, column-type detection, null and duplicate scanning — the foundation, handled automatically.

🔤

Pattern checks

Whitespace issues and format mismatches (like malformed emails) caught before they reach a dashboard.

🤖

ML anomaly detection

Isolation Forest learns your data's own distribution and explains, in plain English, why a row was flagged.

📈

Suggested KPIs

Based on the columns actually present, get suggested metrics an analyst could build next.

💬

Ask-the-report chat

Question the results in plain English — grounded strictly in your report, not invented.

📄

PDF export

Take the summary, the flagged rows, and the suggested KPIs with you as a shareable document.
